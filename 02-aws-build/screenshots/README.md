# AWS Screenshot Evidence

Screenshots in this folder are implementation evidence for the AWS work completed so far.

- `account-security/` - IAM identities, password policy, administrator group, budget and SSM role evidence
- `network-foundation/` - VPC, subnet, IGW, route-table and security-group evidence
- `ec2-deployment/` - launch configuration, Elastic IP, SSM validation and final Scenario 01 instance inventory
- `route53-domain/` - parent DNS migration, child hosted zone, delegation, authoritative tests, public resolver validation and final DNS sanity checks

Primary screenshots are displayed inline in the relevant technical documents so a reader can follow the implementation without opening every image separately. Supporting screenshots remain available through each document's evidence index.

Credential material, MFA QR codes, API keys, private keys and raw secrets are intentionally excluded.
